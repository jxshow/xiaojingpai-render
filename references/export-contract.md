# 预览、复制、微信保存：三个不同的检查层

1. 输入层：原文有没有丢、prompt 是否逐字保留、一个 quote 是否仍是一个块。
2. 本地导出层：生成片段不包含控件；文字是可选 DOM；text/html 和 text/plain 都齐全；图片比例正确。
3. 公众号层：粘贴到新草稿 → 保存 → 重新打开 → 手机预览。只有实际完成才能报告微信验证通过。

微信编辑器可能重写结构/样式、处理外部图片，具体行为随平台变化。span leaf 只是冗余样式承载，不是官方保证。纯文本保存成功也不能证明富文本保存成功。

## 本版导出约束

- 根 section 白底、无固定尺寸、padding:0；不复制预览页底色、工具栏或选择外框。
- 样式内联；品牌色带可用linear-gradient且提供背景实色，正文重点默认逐字着色（不是透明字）；纯色稳妥版移除渐变。两版都不依赖 CSS 类、变量、脚本、外部字体、flex/grid 或绝对定位。
- 不输出编辑态 contenteditable、选区蓝杠、data-*、按钮、SVG 图标或弹窗。
- prompt 导出不含 max-height、overflow:auto/hidden，完整原文在一个可扩展块里。
- 引用多个段落共享一个外框；不靠空 p 或 br 撑高度。
- 图片 height:auto、max-width:100%、display:block；媒体容器无固定高/比例占位；不复制编辑器缩放后的像素高度。
- 原始提示词/代码的空格不改成全角空格；HTML 转义保证内容不被执行。
- 缺图、图片本地路径、远程图片尚未在微信内确认，必须明示。不要自动偷偷删除图片让检查变绿。

## 复制失败/样式丢失/无法保存时

先区分：浏览器没写入剪贴板？粘贴后样式变了？微信点击保存报错？不要把三者混成一个原因。
检查实际 Clipboard text/html 的范围与大小，确认复制的是 article.html 中的根 section，不是整个页面；在空白草稿对照一小段纯正文，再依次加标题、引用、提示词、图片来定位。
查看控制台/微信提示与失败内容；若无法访问后台，就列明限制，不能声称根因已证实。换托管服务器通常不改变剪贴板 HTML 结构，不把迁移腾讯云当作默认修复。

预览只复制提示词按钮输出原始纯文本（供 AI 对话框）；复制全文输出文章 HTML + 可阅读纯文本（供公众号）。二者不要混用。

## 渐变的三个层次

1. 色块/底带渐变：linear-gradient作为背景；渐变失效不改变黑色标题，色块以实色背景兜底。用户图1直接展示了编辑器内渐变，并不能因此保证所有样式或再次保存都保持。
2. 默认重点字steps：按字素把 #2ea250→#09fc3c 插值为各字色。是真文字，渐变是逐字阶梯近似，不冒称连续像素裁剪；没有透明文本和底线。复制/选字仍可操作。
3. continuous连续字形渐变：background-clip:text与透明填色配合，提供背景色兜底。但若平台只保留部分CSS，可能出现色块或文字不可见。仅显式选择并实测；纯色稳妥版完全移除此风险属性。

没有找到可据以保证当前公众号文章编辑器行为的完整官方CSS白名单。不要引用小程序CSS文档来证明公众号文章支持度。MDN的浏览器支持也不等于微信编辑器过滤规则。
技术依据：[MDN background-clip](https://developer.mozilla.org/en-US/docs/Web/CSS/Reference/Properties/background-clip)、[MDN background-image](https://developer.mozilla.org/en-US/docs/Web/CSS/Reference/Properties/background-image)。
