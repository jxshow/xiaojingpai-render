配方（不机械套空章节）：

- 工具实测：原文开场 → 适用任务 → 实测过程/配图 → 结果与局限 → 署名。
- 操作教程：目标 → 已有准备 → 有序步骤 → 提示词/代码 → 验收方法。
- 提示词分享：用途/条件 → 完整 prompt 卡 → 参数说明 → 实例/限制。
- 观点长文：引入 → 原文论点层级 → 证据/引用 → 原结论。无证据不杜撰“实测”。

署名不计为内容章节；目录只有原文较长且有助阅读时生成，使用真实章节的导读卡或文字列表，不伪装可跳转导航。
