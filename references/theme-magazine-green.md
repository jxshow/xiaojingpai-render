# 鲸选杂志绿

原型是 gzh-design 的“摸鱼绿（绿色杂志风）”：图2可对应 cover-breaking、toc-scroll 与 PART 章节。不采用摸鱼票据风的票券造型。

## Tokens

主色 #2ea250 → #09fc3c；黑色 #1d2129、灰蓝正文 #4e5969、浅绿 #f3fbf4。原emerald色替换为鲸选品牌色；无黄色重点底线。

## 组件

- cover：栏目/日期 → 黑色标题 → 渐变重点副句 → 一行说明 → 品牌渐变色带。真实DOM，无截图代替标题。可省字段整段省略，不制造空位。
- toc：146px卡片自然换行，手机两列、宽屏可四列，不将内容放进只能横滑才能看到的区域。只列真实章节，不强制PART或英文标签。
- summary：一句话提要，浅绿虚线框，重点字渐变、无小标题底线。
- H2：同一行“01 标题”，删掉原左数字下PART、竖线、英文副题。保留清晰层级，中文为主。
- H3：黑色加粗，2px绿底线；mark：绿色渐变字，无底线；strong：只加粗。

## 骨架与配方

cover → toc（多节且有帮助时）→ summary（原文已有或已授权撰写）→ 自然段 → H2/H3 → 引用/图/提示词 → 结语 → 署名。
工具盘点可将cover换成简洁title，但不同时重复标题；观点长文少用目录卡；具体模板按内容删减。

## 输入映射

普通Markdown采用共同映射。封面/导读是额外语义块，按 input-and-ir 的cover/toc/summary字段生成，不把“原文没有的信息”当装饰补进去。
